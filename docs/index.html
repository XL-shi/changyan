核心功能

开口，让双手自由

输入任意应用
文字直接输入到当前光标位置，无需切换窗口，适用于所有应用——邮件、文档、代码编辑器、聊天窗口。
本地优先，隐私安全
API 密钥仅存储在本地，macOS 使用系统 Keychain 加密。BYOK 模式下音频不经过 ChangYan 服务器。
20+ 语言识别
支持中文、英语、日语、韩语、法语等 20 余种语言，自动检测，还可实时语音翻译输出。
AI 智能润色
接入任意 LLM 自动修正语法、补全标点、优化表达。口语变书面，说完即可用。
历史记录
所有转录记录本地存储，支持搜索和回溯，随时复用之前的内容。
实时语音翻译
独立翻译快捷键，说中文输出英文，或任意语言组合，边说边译。

使用方式

三步，开始语音输入

1
下载安装
下载 .dmg，拖入应用程序文件夹，启动 ChangYan
2
填入 API Key
在设置中填入 Deepgram 等 STT 服务的 API 密钥
3
开口即用
按住全局快捷键开始录音，松开后文字自动输入到光标处
